# Prg — прогресс монтажа по объектам

Один файл на объект:

- `SOU001.html` — ГКУЗ ЛО «Ульяновская психиатрическая больница», шесть корпусов.

Страница собирается в вечернем цикле из кабельных журналов, спецификаций и BIM-моделей,
вручную не правится. Перед публикацией проходит проверку `checklist_43a.py`: сроки ПНР,
цвета и проценты «Хода работ», средневзвешенные донаты, оформление и арифметика снабжения.

Индексация закрыта: `robots.txt` в корне и `noindex` в каждой странице.
