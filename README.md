# SOU — страницы по объектам

Статические страницы: часть открывается по QR-кодам на объектах, часть — по прямой
ссылке у заказчика.

| Раздел | Что внутри |
|---|---|
| `Prg/` | Прогресс монтажа по объектам, один файл на объект: `SOU001.html`, дальше `SOU002.html` и т. д. |
| `zh/b/` | Женское отделение — бирки кабельных отрезов (ход отреза, схема, озвучка) |
| `zh/p/` | Женское отделение — прогресс СМР |

## `Prg/` — прогресс монтажа

Страница объекта: ход работ по этапам с процентами и сроками ПНР, объёмы «проект →
деталировка → на объекте», аксонометрии из BIM-моделей и сводка снабжения по всем
корпусам. Вкладка на корпус.

- СОУ001 «Ульяновская ПБ» — [Prg/SOU001.html](https://estroyclaude.github.io/SOU/Prg/SOU001.html)

Обновляется в вечернем цикле: после разбора отчёта бригады страница пересобирается
и коммитится сюда, Pages публикует её за пару минут по тому же адресу. До 19.09.2026
файл заливался в Битрикс вручную — этот шаг убран.

Перед публикацией страница проходит проверку `Скрипты/checklist_43a.py`: даты и сроки
ПНР, цвета и проценты «Хода работ», средневзвешенные донаты, оформление статусов
снабжения и арифметика его слагаемых.

## Общее

Страницы генерируются из кабельного журнала и BIM-модели, вручную не правятся.
Индексация поисковиками закрыта: `robots.txt` и `noindex` в каждой странице. Репозиторий
публичный, поэтому в страницах нет фамилий, стоимостей и персональных данных — только
объёмы работ, статусы и сроки.
